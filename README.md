## Решение по видеоконсультациям

**Вопрос заказчику:** Видеозвонок должен быть встроен в приложение или достаточно перехода во внешний сервис?

**Категория MoSCoW:** Should (для первой версии).

**Влияние на сроки:** Осталось 54 SP при velocity 18 SP/итерацию — это ~3 итерации, а до конца проекта осталось тоже 3. Свободного места нет.

**Влияние на бюджет:** Потрачено 45% при готовности 40%. Новая функция потребует доп. часов и, возможно, платного сервиса.

**Решение:** упростить (внешний сервис) либо перенести на следующую версию.

**Почему:** Текущий бэклог уже заполняет оставшееся время. Сначала уточняем объём, затем согласуем с заказчиком.
